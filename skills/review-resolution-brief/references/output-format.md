# Output format

Use the following Markdown headings in English and Chinese:

1. `# Review Resolution Brief / 审查闭环简报`
2. `## Scope / 范围` — packet and commit identifiers, plus live-access statement.
3. `## Findings / 意见处理` — one row per comment: ID, request, claimed response, verification evidence, status, next check.
4. `## Re-review checklist / 复审清单` — ordered actionable checks.
5. `## Evidence gaps / 证据缺口` — data absent from the packet.

Use a table for findings. Never insert invented URLs, test results, commit IDs, reviewer decisions, or resolved-thread state.
